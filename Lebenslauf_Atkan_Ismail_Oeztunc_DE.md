### git-secret-scan | Python / Security

Pre-Commit-Hook + GitHub Action, die verhindert, dass API-Schlüssel und Tokens in Commits gelangen.

**Belege:** 98 Tests, 98 % Coverage, beschrifteter Benchmark mit 100 % Precision / 100 % Recall, Maskierung und Fail-Closed-Fehlerbehandlung.

### postgrest-keyset-page | Node.js / Backend

Dependency-freie Keyset-Pagination für PostgREST-ähnliche REST-APIs, entwickelt gegen stillen Datenverlust oder Duplikate bei parallelen Änderungen.

**Belege:** Regressionstest für den Fehlerfall, 9 Tests, CI auf Linux/macOS/Windows, Node 18 und 22.

Read-only-GitHub-Assistent, der eigene Repositories überwacht, ungeeignete Contribution-Möglichkeiten filtert, Issues bewertet und die Gründe für Vorschläge erklärt.

**Belege:** 58 Tests; die Read-only-HTTP-Grenze wird technisch erzwungen und getestet.
